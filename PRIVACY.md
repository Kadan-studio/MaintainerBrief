# Privacy

MaintainerBrief processes the current supported GitHub page locally in the browser when the user invokes the extension.

It may read:

- repository name
- Issue or Pull Request number
- page title
- page URL
- Issue or Pull Request description
- text the user has actively selected on the page

This data is used only to generate structured clipboard content.

- Page data is not persisted or saved by MaintainerBrief.
- Page data is not transmitted externally.
- MaintainerBrief does not use analytics or telemetry.
- MaintainerBrief does not call the GitHub API.
- MaintainerBrief does not call an AI API.
- MaintainerBrief does not use a backend or external network service.
- Clipboard content is written only when the user presses one of the Copy buttons.
