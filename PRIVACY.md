# Privacy

MaintainerBrief processes supported GitHub page data locally in the browser when you open the extension.

- It does not collect user data.
- It does not store user data.
- It does not transmit data externally.
- It does not use analytics or telemetry.
- It does not call the GitHub API.
- It does not call an AI API.

The extension reads only the current supported GitHub page when invoked, and writes generated text to the clipboard only after the user presses a copy button.
